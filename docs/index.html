TRINETRA Privacy Policy

Effective: 22 September 2026

Prototype privacy promise: TRINETRA performs package-risk analysis and screen-time summaries on the Android device. Version 0 has no server account, advertising SDK, analytics SDK or cloud database.

Data processed

When you choose a feature, TRINETRA may process installed package names, requested app permissions, install source, app-usage totals, latest available device location, battery level, parent phone number entered on screen and a timestamp.

How data is used

Package data is compared locally with a bundled public stalkerware indicator list and local risk rules. Usage totals are shown locally. The SOS feature prepares an SMS in your phone's messaging app; you review and send it. TRINETRA does not silently send the message.

Sharing and retention

Version 0 does not transmit processed data to CYBER Helps Technology. The SMS app and mobile carrier process an SOS only if you choose to send it. TRINETRA does not retain scan or usage results after the app process is closed.

Permissions

Package visibility supports the APK Shield's core security scan. Usage access is optional and opens Android's own special-access settings. Location is optional and used only while preparing SOS content. TRINETRA does not use Accessibility services and does not read other apps' messages.

Children and safety

A parent or guardian should supervise setup for a child. Risk labels are triage signals, not forensic proof. Removing suspected monitoring software may alert an abuser or destroy evidence; make a safety plan first.

Your choices

You can deny or revoke location and usage access in Android Settings, clear app data, or uninstall TRINETRA.

Contact

For privacy questions, contact CYBER Helps Technology Pvt Ltd through the project repository.
